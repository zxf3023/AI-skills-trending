GitHub 热门榜报告一键生成器 · 使用说明
================================================

【一、首次使用（换电脑后请先看这里）】

1) 本程序需要电脑上已安装 Python 3.8 或更高版本。
   下载地址：https://www.python.org/downloads/
   安装时务必勾选 “Add python.exe to PATH”（加 PATH），否则脚本找不到解释器。
   不需要 pip 安装任何第三方库，程序只用 Python 标准库。

2) 双击“一键生成报告.bat”即可启动：
   - 正常情况：弹出图形界面，选好参数后点“一键拉取并生成报告”；
   - 若系统缺少图形库（tkinter）：自动切换为命令行模式，跑完直接打开浏览器；
   - 若电脑没装 Python：会提示安装地址并停住，不会一闪而过。

【二、常见报错对照】

· 'xxx' 不是内部或外部命令
  多为 .bat 被编辑器/压缩工具改成了 LF 换行或加了中文注释，导致 cmd 把注释当命令执行。
  本文件夹内已提供修复版 bat（纯英文内容 + CRLF 换行），请使用它。

· 系统找不到指定的路径
  旧版 bat 里写死了原电脑的 Python 路径（C://Users//<用户名>//...），换机后不存在。
  修复版改为自动探测：py -3 → python → 微软商店 Python，逐个尝试。

· 界面没弹出但程序在跑
  说明缺少 tkinter（部分精简版 Python），程序会自动转命令行模式，属正常现象。

· 检索失败：HTTP Error 403: rate limit exceeded
  GitHub 对“检索类”接口有严格限流：未登录状态每个 IP 每分钟只能请求 10 次，
  超了就叫你还等一会儿（程序会自动等待并重试，不是报错退出）。
  本版已做三件事把影响降到最低：
    ① 请求间隔从 9 秒压到 7.5 秒，并支持按接口返回的“重置时间”精确等待；
    ② 单个接口失败不再中断整份报告，其他榜单照常生成；
    ③ 支持用 Token 把限额从 10 次/分钟提到 30 次/分钟（推荐，见下）。
  配置方法二选一：
    方式 A（推荐）：直接在图形界面的“GitHub Token”一栏粘贴后点「确认」，当场生效，
                    不用重启程序，也不依赖环境变量。
    方式 B（命令行/环境变量）：
    a. 登录 GitHub，打开 https://github.com/settings/tokens
    b. Generate new token → 选 Classic → 不勾任何权限（只读公开数据即可）→ 生成
    c. 复制生成的 token，在“此电脑”上右键 → 属性 → 高级系统设置 → 环境变量
       → 新建用户变量：变量名 GITHUB_TOKEN，变量值粘贴 token → 确定
    d. 重新双击 bat。日志里会提示“已启用 GitHub Token，检索限额 30 次/分钟”。
  注意：Token 只存在你自己电脑的环境变量里，程序不会上传、不会写入报告。

【三、图形界面参数说明】

· 输出目录：报告 HTML 保存位置，可点“浏览…”选择；默认脚本所在目录。
· 搜集榜单：总榜 / 月榜 / 周榜 / 日榜，可任意勾选。
· 每榜数量：AI 与 Agent Skill 分别设置（1-100）。
· GitHub Token（可选）：粘贴一个只读 Token 后点「确认」，程序会当场校验并显示
  账号名；校验通过后检索限额从 10 次/分钟提到 30 次/分钟，整轮能快 1-2 分钟。
    - 点「获取 Token…」直接打开 GitHub 生成页（选 Classic，不用勾任何权限）；
    - 输入框默认以圆点遮蔽，需要核对时勾「显示」；
    - 留空即跳过，一切照常，只是慢一些；Token 无效会在开始时直接提示，不会白跑。
    - Token 只保存在当前这次运行的内存里，不写文件、不上传。
· 输出范围：
    全部              —— Agent Skill 版块 + AI 版块，两块分别展示
    只输出 Skill 项目 —— 两版块中的 Agent Skill 项目合并去重后单块展示
    只输出 AI 项目    —— AI 版块剔除 Agent Skill 项目后的其余项目

  报告正文结构（已不含趋势分析版块）：
    全部模式  ：1.1 Agent Skill 项目总表 → 1.2 Agent Skill 项目详细解读
                → 1.3 其他项目总表 → 1.4 其他项目详细解读
    Skill 模式：1.1 Skill 项目总表 → 1.2 Skill 项目详细解读
    AI 模式  ：1.1 AI 项目总表 → 1.2 AI 项目详细解读

【四、命令行用法（可选）】

python github_trending_report.py --cli
     --out-dir "D://报告" --boards 总榜,日榜 --topn-ai 20 --topn-sk 50 --only all|skill|ai
     [--token ghp_xxx]        传入 GitHub Token（可选，提高限额）
     [--check-token]          只校验 Token 是否有效后退出

【五、文件清单】

使用说明.txt                本文件

【六、注意事项】

· 单次运行约 2-5 分钟，主要耗时在 GitHub 接口的限流等待间隔；
· 需要联网（访问 github.com 与 api.github.com）；
· 报告文件名带时间戳，重复运行不会覆盖旧报告；
· 数据为实时抓取，星数与榜单排名每次都会变化。
